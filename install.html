📱 Instalar Termux en Pixel

Cargando versión más reciente…
Detectando arquitectura del dispositivo…
1
Pulsa el botón de descarga. Chrome descargará el APK a tu carpeta Descargas.
2
Abre el APK desde la notificación o desde Descargas.
3
Android pedirá permiso para instalar apps de fuentes desconocidas — acéptalo para Chrome.
4
Pulsa Instalar y abre Termux.
⬇ Descargar Termux (detección en curso…)

Después de instalar Termux

5
En Termux, pega y ejecuta:
pkg install -y git
git clone https://github.com/espheral/- ~/setup
cd ~/setup && bash setup.sh
Ver todas las releases en GitHub
⚠ No se pudo detectar la arquitectura automáticamente. Si tu Pixel es de 2016 o posterior, usa arm64-v8a.
Termux es software libre — github.com/termux/termux-app
